# Student Performance Data Analysis

## Overview
This beginner-friendly data science project explores student performance using Python, Pandas, Matplotlib, and Seaborn.

## Dataset
- 5,000 student records
- 16 columns
- Includes study hours, attendance, subject scores, final percentages, performance levels, and pass/fail results.
- No missing values or duplicate rows were found during the initial data quality checks.

## Analysis
- Overall final percentage statistics
- Performance-level distribution
- Pass/fail distribution
- Average study hours by performance level
- Average attendance by performance level
- Average Math, Science, and English scores
- Correlation between study hours and final percentage

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## How to Run
1. Clone or download this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open `student_performance_analysis.ipynb` in VS Code or Jupyter.
4. Run the notebook cells in order.

## Key Finding
The observed correlation between daily study hours and final percentage was approximately -0.013, indicating almost no linear correlation in this dataset. Correlation does not establish causation.
